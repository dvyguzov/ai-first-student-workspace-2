# Рубрика AI-first занятия 2–4

**id:** `hw-check-ai-first`

Полные чеклисты у преподавателя: `docs/qa-guru/ai-first-qa/lesson-0N/checklist-submission-homework.md`. Здесь — сжатая рубрика для self-check.

## Занятие 2 (rules + skills)

| Критерий | Вес |
|----------|-----|
| Rule: контракт среза (команда + exclude screenshot/visual как в репо) | 25% |
| Rule: safety (commit + allure-results) | 15% |
| Skill: структура (3 сценария + DoD, свои имена) | 25% |
| Skill: воспроизводимость (новый task → те же flags) | 25% |
| Артефакты (2 скрина + текст) | 10% |

Авто-незачёт: простыня >250 строк; rule противоречит skill; агент закоммитил сам.

## Занятие 3 (RAG)

| Критерий | Вес |
|----------|-----|
| Плохой vs хороший промпт (вся папка vs 2–4 чанка) | 40% |
| В хорошем ответе класс#метод, код не писал | 40% |
| Артефакты (2 скрина + 2–3 предложения) | 20% |

Авто-незачёт: единственный промпт «прочитай весь rag»; новый `*Tests.java`; выдуманный `testE2e`; агент закоммитил сам.

CI / sync / DNS — не этот зачёт (хвост занятия 3, позже).

## Занятие 4 (ADR)

| Критерий | Вес |
|----------|-----|
| ADR: контекст + решение + последствия | 60% |
| Файл `007-*.md`, не копипаста 005, не `006` | 25% |
| Отличил ADR от RAG (2–3 предложения) | 15% |

Авто-незачёт: файл `006-*.md`; новый тест; таблица покрытия вместо ADR; агент закоммитил сам.

Пирамида / audit — следующее занятие, не этот зачёт.

## Don't

- Проверять диплом Java/Python этим чанком
- Путать с `qa-review-framework`
