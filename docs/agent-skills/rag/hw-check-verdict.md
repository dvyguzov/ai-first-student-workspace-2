# Вердикт сдачи занятия

**id:** `hw-check-verdict`

Один статус: **принято** / **не принято** / **ожидает проверки** (нет скрина, нет файлов).

Порог занятия ≥ 70% по таблице чеклиста, если нет авто-незачёта.

## Ответ

Таблица: критерий | вес | pass/fail | что исправить.  
Потом статус и короткий комментарий (привет → список, если незачёт → «ожидаю правок»).

## Don't

- Баллы вне рубрики занятия
- Commit за студента
- «Почти принято» как статус
